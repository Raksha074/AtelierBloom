AtelierBloom 🌸

Welcome to the AtelierBloom repository! This project is a modern e-commerce web application built for a boutique flower shop, offering a seamless experience for browsing and purchasing beautiful floral arrangements.

🌻 About The Project

AtelierBloom provides an elegant online storefront where customers can explore seasonal blooms, order custom bouquets, and arrange for fresh flower deliveries. Built with performance and user experience in mind, it brings the beauty of a local florist straight to the web.

✨ Key Features

Curated Collections: Browse through various categories like weddings, anniversaries, birthdays, and seasonal specials.

Custom Arrangements: Interactive options for users to customize their bouquet sizes, vases, and floral combinations.

Seamless Checkout: A smooth and secure shopping cart experience.

Responsive Design: A beautiful, mobile-friendly interface that looks stunning on any device.

🚀 Tech Stack

Framework/Bundler: Vite

Language: TypeScript

Package Manager: npm

Configuration: TanStack Config

🛠️ Getting Started

Follow these instructions to set up the project locally on your machine.

Prerequisites

Make sure you have Node.js installed on your system.

Node.js (v16 or higher recommended)

Installation

Clone the repository:

git clone https://github.com/yourusername/AtelierBloom.git


Navigate into the project directory:

cd AtelierBloom


Install the dependencies:

npm install


💻 Available Scripts

In the project directory, you can run the following commands:

npm run dev

Starts the development server. Open http://localhost:5173 to view it in your browser. The page will automatically reload when you make changes.
